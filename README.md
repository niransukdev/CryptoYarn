# CryptoYarn

CryptoYarn is a high-performance, real-time data processing system for cryptocurrency transactions, utilizing auto-scaling and advanced protocol optimization.

With CryptoYarn, you get a lightweight tool that stays out of your way.

**What you get**

- CryptoYarn is a high-performance, real-time

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CryptoYarn.git`
2. `cd CryptoYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

CryptoYarn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
